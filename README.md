A modular **Compliance-as-Code** evaluation engine designed to continuously audit, verify, and document cloud infrastructure posture against European and global regulatory frameworks.

Instead of relying on manual point-in-time screenshots or passive questionnaire platforms, this repository translates complex regulatory mandates (DORA, ISO 27001, SOC 2, PSD2) into **executable code, automated monitoring, and auditor-ready evidence generation**.
